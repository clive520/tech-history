# 微軟史上最兇狠的割喉戰！比爾蓋茲如何用「免費綁架」絞殺網景，引發差點拆分微軟的世紀大審判？

> **時代座標**：1994 年 - 2001 年  
> **領銜人物**：馬克·安德森（Marc Andreessen）、吉姆·克拉克（Jim Clark）、比爾·蓋茲（Bill Gates）、史蒂夫·鮑爾默（Steve Ballmer）、大衛·波伊斯（David Boies）、托馬斯·潘菲爾德·傑克遜（Thomas Penfield Jackson）  
> **核心突破**：網景 Navigator 掀起了全球商業網際網路的創世紀狂潮，並提出「瀏覽器即通用作業系統平台」的革命性構想，正面威脅微軟 Windows 王座。微軟發動了商業史上最凶暴、最冷酷的「抽乾對手氧氣」（Cut off their air supply）割喉戰——透過零元免費、作業系統底層釘死綑綁以及對 PC 大廠的鐵腕封鎖，將網景活活窒息；隨之引爆美國司法部歷時數年的世紀反壟斷大審判，差點將這座萬億科技帝國大卸八塊。

## 一、 彗星撞地球：赤腳大學生、20 億美元 IPO 與「Web 顛覆論」

1995 年 8 月 9 日的紐約華爾街，上演了一場徹底顛覆現代金融與科技歷史的狂歡。

一家成立僅僅十六個月、營業額微不足道、**甚至帳面上連一分錢利潤都沒賺過**的小公司，正式在那斯達克掛牌上市。這家公司的股票代號是 NSCP——**網景通訊公司（Netscape Communications）**。

原本承銷商摩根士丹利將發行價定在每股 14 美元，但在開盤前的幾分鐘內，來自全球投資者的買單像雪崩一樣湧入，發行價被緊急調高到 28 美元。開盤那一瞬間，股價直接跳漲至 71 美元，盤中最高衝破 74.75 美元！當收盤鐘聲敲響時，這家年輕公司的市值直接飆破了 **20 億美元**。

在華爾街歷史上，從未有一家虧損企業能享受如此狂熱的膜拜。

```text
【網景 IPO 的狂暴數字與文化衝擊】
┌────────────────────────────────────────────────────────┐
│ 公司年齡：僅僅 16 個月                                 │
│ 獲利狀態：虧損 430 萬美元（0 營利）                    │
│ 首日市值：20 億美元（創下全球科技業神話）              │
│ 旗艦產品：Netscape Navigator 1.0（市佔率突破 80%）     │
│ 時代符號：24 歲的馬克·安德森赤腳登頂《時代》雜誌封面   │
└────────────────────────────────────────────────────────┘
```

登上《時代》（*Time*）雜誌封面的，是這家公司的靈魂人物——年僅 24 歲的**馬克·安德森（Marc Andreessen）**。

就在兩年前，安德森還只是伊利諾大學厄巴納-香檳分校國家超級電腦應用中心（NCSA）的一名時薪 6.85 美元的工讀大學生。在那裡，他與好友艾瑞克·比納（Eric Bina）寫出了世界上第一款普及的圖形化瀏覽器 **NCSA Mosaic**，第一次讓網頁不再只有枯燥的文字，而是能夠在同一頁面內顯示彩色圖像。

矽谷傳奇硬體巨頭 SGI（Silicon Graphics）創辦人**吉姆·克拉克（Jim Clark）**看見了安德森身上的天才光芒，立刻開出一張支票將安德森及其大學團隊整批打包挖到矽谷，成立了網景。

1994 年底，網景推出了代號「馬賽克殺手」（Mosaic Killer，簡稱 Mozilla）的 **Netscape Navigator 1.0**。這款瀏覽器具備革命性的多執行緒載入技術，當使用者在慢如蝸牛的 14.4k 撥接網路下打開網頁時，文字會先瞬間彈出，圖片在後台漸進渲染，甚至還加入了點擊連結時發光的金色船舵（Ship's Helm）動畫。在短短不到幾個月內，Navigator 席捲了全球各大校園與家庭，市佔率如野火燎原般衝破 **80%**。

更讓西雅圖雷德蒙德感到脊背發涼的，是年輕狂妄的安德森面對《彭博》與《紐約時報》時吐出的驚天豪言：
> **「在未來的網際網路時代，瀏覽器將會演化為全新的跨平台作業系統！軟體開發者只需要為瀏覽器寫 Web 應用，使用者根本不需要在乎底層是什麼系統。未來的 Windows，只不過是一組微不足道、隨時可以被拔除替換的設備驅動程式（a poorly debugged set of device drivers）罷了！」**

安德森這句不可一世的挑釁，如同點燃了一顆核彈，直接在比爾·蓋茲的臥室裡炸響。

## 二、 恐慌的雷德蒙德：山景城密會與「抽乾他們的氧氣」

1995 年 5 月底，微軟雷德蒙德總部陷入了一場極致的白色恐怖。

當時微軟全公司正將所有籌碼壓在即將發布的 Windows 95 上，但比爾·蓋茲卻在深夜看見了這座宏偉大廈地基崩塌的致命裂痕。5 月 26 日，蓋茲寫下了微軟歷史上最具分量的作戰動員令——**《網際網路海嘯》（The Internet Tidal Wave）**。

蓋茲在信中毫不掩飾他對網景的極度恐懼：
> **「網際網路是一場改變所有遊戲規則的超級海嘯！網景正在建立一個獨立於 Windows 之外的應用軟體生態系。如果他們成功了，微軟過去二十年構築的軟體帝國將在一夜之間被徹底邊緣化！」**

```text
【比爾·蓋茲眼中的生死威脅】
過去的個人電腦世界：
使用者 ──> [ Windows 作業系統 (微軟壟斷) ] ──> 應用程式 (Word, Excel)

網景描繪的未來世界：
使用者 ──> [ Netscape 瀏覽器平台 (開放跨平台) ] ──> Web 雲端應用程式
                          │
                          ▼
            [ 底層系統：不管是 Windows、Mac 還是 Unix 都不重要！]
```

### 1. 1995 年 6 月 21 日：山景城的最後通牒
在動刀之前，微軟決定先展現「教父」式的談判手腕。

1995 年 6 月 21 日，一個炎熱的午後，微軟派出由高管丹·尼克（Dan Neukom）帶領的談判代表團，大搖大擺地走進了網景位於加州山景城的總部會議室。

這場長達數小時的秘密會議，在日後被美國司法部列為起訴微軟的頭號呈堂證供。微軟代表向吉姆·克拉克與馬克·安德森遞出了一份近乎黑手黨劃分地盤式的「合作協議」：
- **微軟的要求**：微軟將全權獨佔為 **Windows 95** 開發瀏覽器的權利；
- **給網景的施捨**：網景必須同意退出 Windows 95 平台，微軟允許網景繼續為 Windows 3.1、Macintosh 和 Unix 這些邊緣系統開發瀏覽器；
- **附帶條件**：如果網景點頭，微軟願意入股網景並提供特殊 API；**如果網景敢說「不」，微軟將把網景徹底碾碎。**

年少氣盛的安德森坐在會議桌對面，看著眼前這群西裝筆挺的微軟巨頭，感到一陣徹骨的寒意與荒謬。他當場回絕了微軟的瓜分提議。

會議結束後，微軟代表收拾皮包，臨走前冷冷地拋下一句話：**「既然如此，那我們就在市場上見了。」**

### 2. 「抽乾對手身上的氧氣！」
談判破裂後，微軟內部立刻進入戰時狀態。

微軟副總裁**保羅·馬里茨（Paul Maritz）**在一場向全公司幹部發表的動員大會上，吐出了這場世紀商業大戰最血腥的名言：
> **「我們要扼殺他們的商業模式！我們要向市場免費傾倒瀏覽器，徹底切斷網景身上的氧氣供應（We are going to cut off their air supply）！讓他們眼睜睜看著自己被活活憋死！」**

微軟的第一步，是組建了代號為「托馬斯專案」（Project Thomas）的數百人研發部隊，以每年超過 **1 億美元**的預算全力開發 **Internet Explorer（IE）**。

當時網景的生存命脈，是向個人用戶收取 49 美元的授權費，向企業銷售伺服器軟體。而微軟祭出的第一個核彈，就是**「定價為零」**——微軟不僅將 IE 免費開放給全世界下載，甚至主動出資替各大學與企業免費部署。

然而，單純的免費還不足以消滅網景，因為在當時，網景 Navigator 的技術與體驗遠遠領先於漏洞百出的 IE 1.0 和 2.0。

比爾·蓋茲深知，要徹底斬草除根，必須動用微軟手中最強大的毀滅性武器——**Windows 作業系統在個人電腦市場高達 90% 的絕對壟斷地位**。

## 三、 絞肉機戰場：被斬斷的呼吸管與製造商的背叛

從 1996 年開始，微軟發動了個人電腦歷史上最嚴密、最冷酷的「渠道大圍剿」。

![微軟「抽乾氧氣」割喉戰略全景圖：Windows OS 底層釘死、OEM 鐵鏈封鎖、零元免費捆綁與全方位市場排擠機制](assets/images/netscape_air_supply.jpg)

### 1. 威逼硬體大廠（OEM）：誰敢裝網景，誰就得死
在個人電腦產業鏈中，PC 製造商（如康柏 Compaq、惠普 HP、戴爾 Dell、捷威 Gateway）是使用者接觸軟體的第一道門戶。如果新買的電腦桌面上已經有了瀏覽器圖示，95% 的普通使用者絕不會大費周章再去花錢下載或購買另一款瀏覽器。

網景原本試圖與各大 PC 品牌簽署預裝協議，但微軟立刻揮舞起「Windows 授權契約」的大棒：
- 微軟向所有 OEM 廠商下達死命令：**出廠電腦的桌面與「開始」選單，必須嚴格維持微軟指定的原始樣貌！**
- 任何廠商只要敢在桌面上預裝網景 Navigator 的圖示，或者試圖把 Internet Explorer 的圖示藏進資料夾，**微軟將立刻撤銷該廠商的 Windows 授權優惠，甚至直接終止 Windows 供貨！**

對於當時利潤微薄的 PC 製造商而言，失去微軟的授權折扣無異於自殺。

康柏電腦（當時全球最大 PC 品牌）曾因為與網景簽訂了推廣協議，在幾款新主機上將網景設為預設，並移除了 IE 圖示。微軟銷售主管立刻發出一封措辭嚴厲的最後通牒信，威脅將在三十天內終止康柏的 Windows 95 授權。康柏高層嚇得冷汗直流，火速下令將所有工廠流水線停工，全面刪除網景，跪著把 IE 圖示重新放回桌面的正中央。

### 2. 利誘美國線上（AOL）：背刺網景的致命盟友
當時全美最大的網際網路服務提供商（ISP）是擁有數百萬撥接用戶的**美國線上（AOL）**。AOL 原本一直是網景的大客戶，其內建瀏覽器正是網景的 Navigator。

1996 年初，比爾·蓋茲親自找上 AOL 執行長史蒂夫·凱斯（Steve Case）。蓋茲拋出了一個令凱斯無法抗拒的魔鬼交易：
> **「只要你願意把預設瀏覽器換成微軟 IE，我就把 AOL 的專屬連線圖示，直接內建進全球數千萬台 Windows 95 的桌面『線上服務』資料夾裡！」**

這是一塊價值數億美元的頂級流量肥肉。凱斯毫不猶豫地背叛了網景，轉投微軟懷抱。一夕之間，網景失去了數以百萬計的新增用戶入口。

### 3. 作業系統底層綁定：將 IE 焊死在 Windows 骨髓中
1997 年底，微軟推出了 **Internet Explorer 4.0**，並在隨後發售的 **Windows 98** 中祭出了終極殺招：**系統級深度整合**。

微軟的工程師將 IE 的排版渲染引擎（`MSHTML.DLL`）與 Windows 系統的核心檔案總管（`EXPLORER.EXE`）徹底熔焊在一起。桌面、資料夾檢視、Windows 說明文件，全部共用同一個瀏覽器代碼。微軟甚至在系統中惡意閹割了「反安裝」功能，只要使用者試圖刪除 IE，系統便會彈出警告，聲稱「移除該組件將導致 Windows 系統崩潰」。

在「出廠自帶、零元免費、無法刪除、深度綁定」的四重絞殺下，網景身上的氧氣被徹底抽乾。

網景的市佔率從 1995 年頂峰時期的 **85%**，以斷崖式的速度暴跌：1997 年跌至 50%，1998 年跌至 30%，到了 2001 年，IE 的市佔率高達創紀錄的 **96%**，而網景則被打落塵埃，萎縮至不足 3%。

1998 年 11 月，油盡燈枯的網景公司在萬般無奈之下，以 42 億美元的低價將自己賣給了美國線上（AOL）。那個曾經揚言要將 Windows 貶為驅動程式的 24 歲赤腳天才馬克·安德森，黯然退場。

微軟贏了這場割喉戰。然而，勝利的香檳尚未開瓶，華盛頓司法部冰冷的傳票已經送達了雷德蒙德的辦公室。

## 四、 世紀大審判：美利堅合眾國訴微軟案（United States v. Microsoft Corp.）

1998 年 5 月 18 日，美國司法部長珍妮特·雷諾（Janet Reno）聯同全美 20 個州的檢察長，在華盛頓召開了震動全球財經界的新聞發布會，正式對微軟公司提起反壟斷民事訴訟（案件編號：Civil Action No. 98-1232）。

這場訴訟被全美媒體譽為**「繼 1911 年拆分標準石油、1982 年拆分 AT&T 電信之後，美國歷史上最重大的反壟斷審判」**。

![世紀反壟斷審判高潮現場：1998 年華盛頓聯邦法庭，明星檢察官大衛·波伊斯質問比爾·蓋茲錄影帶，法官與記者屏息凝視](assets/images/microsoft_antitrust_courtroom.jpg)

### 1. 明星檢察官大衛·波伊斯 vs 比爾·蓋茲
美國司法部聘請了全美勝訴率最高、以風格冷酷犀利著稱的傳奇訴訟律師**大衛·波伊斯（David Boies）**擔任首席特別檢察官。

審判的核心焦點直指三個關鍵法律問題：
1. **微軟是否在個人電腦作業系統市場擁有實質壟斷地位？**
2. **微軟將 IE 瀏覽器與 Windows 強行綑綁，是否構成了非法搭售（Tying）？**
3. **微軟威脅 PC 製造商排擠網景的行為，是否構成了濫用市場優勢、扼殺技術創新？**

微軟組建了號稱全美最強大的頂級律師團，辯稱「將瀏覽器整合進作業系統是技術演進的自然結果，就像汽車出廠自帶收音機一樣，完全是為了提升消費者體驗」。

然而，波伊斯在法庭上施展了一場外科手術般的證據毀滅戰。他透過法庭傳票，調閱了微軟內部數百萬封機密電子郵件，將微軟高層那些赤裸裸、充滿江湖黑話的密謀公諸於世：
- 「我們要如何把網景的氧氣抽乾？」
- 「我們的目標就是讓這家公司死透！」
- 「只要他們敢競爭，我們就切斷他們的喉嚨！」

### 2. 那場載入史冊的 20 小時作證災難
1998 年 8 月，比爾·蓋茲在西雅圖接受了長達 20 個小時的審前宣誓作證（Deposition）。波伊斯決定將作證過程全程錄影，並在法庭的電視大螢幕上當眾播放。

這段錄影帶成為比爾·蓋茲人生中最難堪、最狼狽的歷史污點。

在鏡頭前，身價數百億的世界首富顯得極度焦慮、易怒且防禦心極強。他無休止地坐在皮椅上前後瘋狂搖晃身體，目光空洞呆滯，在長達數十秒的死寂停頓後，用含糊其辭的態度反覆回答：
- 「我不記得了。」
- 「我不清楚這封信是誰寫的。」
- 「請問你說的『競爭』（Compete）這個詞，具體法律定義是什麼？」

蓋茲試圖用精明的文字遊戲迴避問題，但他在錄影帶中傲慢無禮、頻頻閃爍的表現，徹底激怒了負責審理此案的聯邦法官**托馬斯·潘菲爾德·傑克遜（Thomas Penfield Jackson）**。法官在筆記中寫道，蓋茲的作證「傲慢、虛偽，對司法缺乏最起碼的尊重」。

### 3. 微軟法庭錄影造假醜聞
審判的高潮出現在微軟試圖證明自己的核心論點之際。

微軟副總裁詹姆斯·阿欽（James Allchin）向法庭提交了一段長達數分鐘的影片示範，試圖向法官證明：**「如果強行將 IE 核心從 Windows 98 中解除安裝，整個作業系統將會瞬間崩潰，無法運行。」**

然而，大衛·波伊斯當晚帶領技術專家徹夜逐幀審查這段影片，赫然發現了一個巨大的破綻——在影片中，螢幕上方的視窗標題列與檔案總管圖示，在不同的鏡頭切換間莫名其妙地消失又出現。

第二天開庭，波伊斯在法庭上當眾拆穿了微軟的謊言：**微軟提交的展示影片根本不是一次連續的真實操作，而是由多段不同的錄影拼接偽造而成！**

微軟的技術專家在證人席上被波伊斯質問得汗流浹背、面紅耳赤，最終不得不當庭結結巴巴地承認「影片確實經過修改與重新錄製」。這場史詩級的造假醜聞，讓微軟在法官心中的信譽徹底破產。

## 五、 帝國裂變與代價：初審拆分、和解與被偷走的十年

2000 年 6 月 7 日，歷時兩年的審判迎來了震驚世界的最嚴厲判決。

托馬斯·潘菲爾德·傑克遜法官正式簽署了最終裁決書，判定**微軟違反了《謝爾曼反壟斷法》第 1 條與第 2 條，濫用壟斷權力扼殺競爭**。法官做出了在科技史上最震撼的懲處命令：

> **「下令將微軟公司正式一分為二：一拆為作業系統公司（專門研發 Windows），另一家為應用軟體公司（研發 Office、IE 及其他軟體）。兩家公司在十年之內不得合併，且微軟必須向全球競爭對手完全公開 Windows 所有的內部核心 API！」**

```text
【2000 年初審法官下令的拆分藍圖】
                  ┌───────────────────────────────┐
                  │ 微軟帝國（Microsoft Corp.）  │
                  └──────────────┬────────────────┘
                                 │ (法院強制拆分令)
                 ┌───────────────┴───────────────┐
                 ▼                               ▼
    ┌─────────────────────────┐     ┌─────────────────────────┐
    │  作業系統獨立公司        │     │  應用軟體獨立公司        │
    │  - 專注研發 Windows     │     │  - 專注 Office 辦公套件 │
    │  - 嚴禁捆綁自研軟體     │     │  - 負責 IE 瀏覽器       │
    │  - 必須向對手公開 API   │     │  - 獨立市場定價銷售     │
    └─────────────────────────┘     └─────────────────────────┘
```

判決出爐當天，全球科技股震盪，微軟股價在一週內崩跌逾 30%，蒸發市值數百億美元。

比爾·蓋茲深感心力交瘁。早在判決前夕的 2000 年 1 月，蓋茲便辭去了微軟執行長（CEO）職位，將帥印交給了史蒂夫·鮑爾默，自己退居「首席軟體架構師」。這位曾經在矽谷叱吒風雲的青年皇帝，在華盛頓司法的鐵拳下顯露出了前所未有的疲態。

### 1. 世紀大逃脫：哥倫比亞特區巡迴上訴法院的逆轉
然而，微軟命運的命懸一線，在隨後的一年裡迎來了戲劇性的逆轉。

微軟龐大的法務軍團向哥倫比亞特區聯邦巡迴上訴法院提起上訴。上訴法院雖然一致同意「微軟確實存在非法維持壟斷的惡劣行為」，但卻意外抓住了傑克遜法官的一個重大司法瑕疵——傑克遜在審判期間，曾多次秘密接受新聞記者的私下採訪，並在言談中將微軟高層比喻為「街頭黑幫打手」。

上訴法院以「主審法官違反司法道德、存在潛在偏見」為由，**撤銷了傑克遜法官的拆分命令**，並將案件發回下級法院重審。

恰逢 2001 年底，小布希（George W. Bush）政府走馬上任，美國司法部的政策風向由民主黨的激進干預轉向保守派的和解主義；加之 911 恐怖襲擊後美國經濟陷入衰退，白宮不希望看到全美最大的科技旗艦企業在動盪中沉沒。

最終，微軟與美國司法部達成了具有里程碑意義的和解協議：
- 微軟免於被拆分；
- 微軟必須向第三方軟體開發商開放 Windows 底層通訊協議；
- 允許 PC 製造商自由預裝競爭對手的軟體，且微軟不得對合作夥伴進行報復；
- 設立由三名獨立技術專家組成的常駐監督委員會，對微軟的代碼進行長達五年的全天候合規審查。

### 2. 被偷走的十年：微軟為割喉戰付出的沉重代價
表面上看，微軟保住了帝國的完整，並徹底消滅了眼中釘網景。但從歷史的宏觀維度來看，**這場割喉戰是微軟商業史上代價最慘痛的一場「慘勝」**。

在整個 2000 年代初期，微軟被長達十年的反壟斷審查繩索死死勒住了脖子。每一行系統代碼、每一次產品改版，都必須經過龐大律師團的層層合規審核。昔日那家敢想敢做、兇狠敏捷的科技巨獸，變成了一頭步履蹣跚、謹小慎微的官僚恐龍。

更諷刺的是，在徹底消滅網景後，微軟解散了絕大部分 IE 研發團隊，將 IE 6 放任自流長達五年不更新，導致其充滿安全漏洞、不遵守 Web 標準，成為全體網頁工程師的共同噩夢。

就在微軟深陷訴訟泥沼、傲慢停滯的這段「被偷走的十年」裡：
- **Google** 悄然崛起，以搜尋引擎重新定義了網際網路的權力中樞；
- 賈伯斯的**蘋果**攜帶著 iPod 與 iPhone 絕地反擊；
- 網景的遺腹子——**Mozilla Firefox** 與後來的 **Google Chrome**，在廢墟上重新奪回了瀏覽器的王座。

## 七、 科技啟示錄：死去的網景，與開源鳳凰的長久復仇

1998 年 11 月，當網景公司即將簽署被 AOL 收購的賣身契、走向生命終點的前夕，網景的工程師們做出了個人電腦歷史上最悲壯、也最偉大的一個決定：

**他們將網景 Navigator 的全部核心原始碼，毫無保留地向全世界公眾開放。**

他們在網景大樓的草坪上立起了一隻巨大的恐龍雕塑，成立了**Mozilla 專案**（Mozilla.org）。網景這艘曾經輝煌的金色帆船雖然沉入了海底，但它的水手們在告別前，把火種撒向了全世界每一個熱愛自由的程式設計師手中。

數年後，從網景廢墟中浴火重生的鳳凰——**Mozilla Firefox** 橫空出世。憑藉著輕巧、快速、對現代 Web 標準的忠實信仰，Firefox 在 2000 年代中葉以摧枯拉朽之勢撕開了微軟 IE 96% 的銅牆鐵壁，重新喚醒了停滯已久的瀏覽器創新。隨後，Google Chrome、Apple Safari 相繼湧現，而曾不可一世的 Internet Explorer，最終在 2022 年被微軟親手永久停用、送進了歷史的博物館。

這場科技史上最凶殘的割喉戰，給人類數位文明留下了一段永不褪色的深刻警示：

**任何一家巨頭，無論其在作業系統的王座上多麼不可一世，無論其壟斷的鐵壁多麼密不透風，也永遠不可能單憑資本與特權，私有化整個人類知識與訊息流通的廣場。**

當大潮退去，那些試圖抽乾對手氧氣的掠奪者，終將在自己構築的封閉溫室中缺氧窒息；而那些將代碼與夢想交給全人類的自由靈魂，哪怕肉身被毀滅，也終將在開源的長河裡獲得永生。
